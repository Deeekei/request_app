# React-фронтенд для системы согласования заявок

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

По умолчанию фронтенд ожидает backend на `http://127.0.0.1:8000`.
При необходимости измените значение `VITE_API_BASE_URL` в `.env`.

## Что реализовано

- React + Vite + React Router
- Многостраничная структура через маршруты
- Авторизация, регистрация, профиль
- Список заявок, карточка заявки, создание и редактирование
- Отправка на согласование, комментарии и история
- Отдельные страницы согласования:
  - `На проверке у ПТО`
  - `На проверке у Директора АСБ`
  - `На проверке у Заказчика`
- Ролевое отображение страниц согласования: каждая страница видна только своей роли
- Красная визуальная тема
- Скрыты системные подписи в интерфейсе: адрес backend и технические названия ручек не выводятся
- В форме материалов используется выпадающий список по названию материала

## Важное ограничение

В backend из архива нет отдельной публичной ручки для получения справочника `agreement_materials`.
Поэтому выпадающий список материалов в React-фронтенде собирается так:

1. из локального каталога `src/data/materialCatalog.js`
2. дополнительно из уже загруженных заявок, если в них есть `material_name`

Если нужен полностью актуальный список материалов из базы, лучше добавить на backend отдельную ручку чтения материалов договора.
